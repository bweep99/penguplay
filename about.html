The PenguPlay Project

Welcome to PenguPlay, an immersive glassmorphism-styled 3D web experience. Built from scratch without external 3D assets, it features procedural rendering of adorable penguins waddling across different dynamic terrains.

Track your high scores, unlock achievements, and customize your profile in this fully interactive game hosted seamlessly on GitHub Pages.
